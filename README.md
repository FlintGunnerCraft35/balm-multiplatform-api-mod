# Balm — Multiplatform Abstraction API

[![Download Latest](https://img.shields.io/github/v/release/FlintGunnerCraft35/balm-multiplatform-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/FlintGunnerCraft35/balm-multiplatform-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

An abstraction layer API letting mod developers write one codebase for Forge and Fabric simultaneously.

![Balm — Multiplatform Abstraction API Preview](https://cdn.modrinth.com/data/MBAkmtvl/285b7bcfd6e525c043e640b08f3efc0cde90f7dd_96.webp)

## Features

- Single codebase targets both Forge and Fabric
- Unified config, network, and registry abstractions
- Used by Waystones, Crafting Tweaks, and more
- GUI and screen helpers with cross-loader support
- Actively maintained with fast new version support

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
